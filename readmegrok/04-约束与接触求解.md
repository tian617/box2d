# 04 · 约束与接触求解

> 读完你能回答：为什么一切约束都长成 `J·V + bias = 0`？顺序冲量在迭代什么？`b2SolveContacts_Overflow` 每一行对应哪项公式？给你两个盒子，你能手算出第一脚冲量吗？

## 一、统一数学：一切都是 `J · V + bias`

2D 刚体有 3 个自由度：`vx, vy, ω`。两个刚体拼成 6 维速度：

```
V = [ vA.x, vA.y, wA,  vB.x, vB.y, wB ]ᵀ
```

约束说的是「某个方向的相对速度该是多少」：

```
J · V + bias = 0      等式：铰链、焊接、马达
J · V + bias >= 0     不等式：接触法向、关节限位
```

`J` 是 1×6 的雅可比（Jacobian）：一行，挑出你关心的那一维相对运动。`bias` 是标量，用来修位置误差、驱动马达、或做推测接触。

### 接触法向的 J

接触点相对质心的杆臂 `rA`、`rB`，法线 `n` 从 A 指向 B。点的相对速度：

```
v_rel = (vB + wB × rB) - (vA + wA × rA)
vn    = dot(v_rel, n)
```

2D 里 `w × r = (-w·ry, w·rx)`，`dot(w×r, n) = w · cross(r, n)`。于是：

```
J = [ -n.x, -n.y, -cross(rA, n),   n.x, n.y, cross(rB, n) ]
J · V = vn
```

约束「不要继续往里走」：`vn + bias >= 0`。

切向摩擦把 `n` 换成 `t = RightPerp(n)`，再减去传送带速度 `tangentSpeed`。

### 冲量必须沿 J 的转置打

虚功原理：约束力不能往约束允许的方向做功，所以力的空间是 `Jᵀ` 的列空间。标量冲量 `λ`：

```
ΔV = M⁻¹ Jᵀ λ
```

`M⁻¹` 是对角块：`invMassA, invMassA, invIA, invMassB, invMassB, invIB`。写开就是你在源码里看到的：

```
P  = λ · n
vA -= invMassA · P
wA -= invIA · cross(rA, P)
vB += invMassB · P
wB += invIB · cross(rB, P)
```

A 被往 −n 推，B 被往 +n 推。作用力反作用力自动满足。

### 有效质量：一脚该踹多狠

把 `ΔV` 代回 `J · V`：

```
Δ(J·V) = (J M⁻¹ Jᵀ) λ = K λ
```

`K` 是标量（一个约束一行）。`1/K` 叫 **有效质量的倒数**，代码里叫 `normalMass`：

```
rnA = cross(rA, n)
rnB = cross(rB, n)
K = invMassA + invMassB + invIA·rnA² + invIB·rnB²
normalMass = (K > 0) ? 1/K : 0
```

直觉：两个物体越轻、杆臂越大（越容易转开），同样相对速度需要的 `λ` 越小。`normalMass` 大 = 「这个方向很钝、需要狠踹」。

想让 `J·V + bias` 变成 0：

```
λ = -normalMass · (vn + bias)
```

不等式再加一条：累积法向冲量不能为负（不能「粘住往回吸」，除非你真做了胶）。

```
λ_acc ← max(λ_acc + λ, 0)
本步真正打出去的 = λ_acc_new - λ_acc_old
```

这就是 **Sequential Impulses（顺序冲量）**：每个约束独立算一脚，立刻改速度，再轮到下一个。数学上是对 LCP 做高斯-赛德尔迭代。不保证一次精确，多扫几遍（在 v3 里「多扫」展开成了子步）就逼近。

```mermaid
flowchart LR
    C1["约束 1 算 λ 立刻改 V"] --> C2["约束 2 看到新 V"]
    C2 --> C3["约束 3"]
    C3 --> C1
```

热启动：上一帧的 `λ_acc` 当这一帧初值。堆叠几乎不动时，第一脚就已经接近正解，后面只微调。

## 二、Overflow 三板斧（对照源码）

图着色失败的接触走标量版。能染色的走 Wide，公式相同。

### Prepare：`b2PrepareContacts_Overflow`

每个大步一次。把 manifold 冻成求解器友好的布局：

1. `indexA/B = bodySimIndex + 1`，0 表示静态（没有 State）。
2. 拷 `invMass`、摩擦、滚动阻力、`tangentSpeed`。
3. 一方静态 → `staticSoftness`，否则 `contactSoftness`。
4. `rollingMass = 1 / (invIA + invIB)`。
5. 每个点：
   - 热启动：`normalImpulse = warmStartScale * mp.normalImpulse`
   - `anchorA/B` 冻在 **大步开始** 的世界杆臂上（接触锚点子步内不随 `deltaRotation` 转——注释说转了更不稳）
   - `baseSeparation = separation - dot(rB - rA, n)`  
     后面当前分离 = `baseSeparation + dot(ΔpB-ΔpA + rot(ΔqB,rB)-rot(ΔqA,rA), n)`
   - `normalMass` / `tangentMass` 按上面的 K
   - `restitutionVelocity` 从接近速度和 e 算好，低于阈值则为 0

文件头注释把 `s(t)` 的展开写完了，建议先读那 8 行再看循环。

### WarmStart：`b2WarmStartContacts_Overflow`

每个小步、积分速度之后：把累积的法向+切向+滚动冲量再打一遍。否则子步一开始速度是「只受了重力」，堆叠会先塌一截再被求解拉回来。

静态侧读 dummy identity。只写回带 `b2_dynamicFlag` 的 State。

### Solve：`b2SolveContacts_Overflow(context, useBias)`

每个点：

```c
ds = (deltaPosB - deltaPosA) + rot(dqB, rB) - rot(dqA, rA)
s  = baseSeparation + dot(ds, n)

if (s > 0)
    velocityBias = s * inv_h;              // 推测：步末刚好碰上
else if (useBias)
    velocityBias = max(massScale * biasRate * s, -contactSpeed);
    // 重叠：软约束推开，速度封顶
    使用 massScale、impulseScale
else
    // Relax：不用重叠 bias
    若 restitutionVelocity > 0：
        velocityBias = min(velocityBias, -restitutionVelocity);

vn = dot((vB + wB×rB) - (vA + wA×rA), n)

impulse = -normalMass * (massScale * vn + velocityBias)
        - impulseScale * normalImpulse      // 软约束对旧 λ 的记忆

newImpulse = max(normalImpulse + impulse, 0)
impulse    = newImpulse - normalImpulse     // 只打增量
打到 vA,wA,vB,wB
```

然后，**仅当 `useBias == false`（Relax）**：

1. 所有点都分离了 → 清掉 `restitutionVelocity`，避免连弹。
2. 滚动阻力：`Δλ = -rollingMass · (wB - wA)`，钳到 `|λ| ≤ ρ · Σλn`。
3. 摩擦：`vt = dot(v_rel, t) - tangentSpeed`，`λt` 钳到 `|λt| ≤ μ · λn`（库仑锥）。

Solve 阶段只做法向。先把「别穿模」稳住，再在松弛里谈弹、滚、滑。这是堆叠不跳的关键顺序。

### Store：`b2StoreImpulses_Overflow`

把 `λn`、`λt`、`totalNormalImpulse` 写回 manifold，供下一帧热启动和 hit 事件。hit 还要求「接近速度快」且「这帧真的打出过法向冲量」——纯推测、没碰上的点不报撞击。

## 三、完整手算：盒子砸在地面一角

数字故意取得好算。对照公式走两轮，比看十遍注释有用。

### 场景

```
        +-------+
        |   B   |     质心 (0, 0.5)
        +---*---+     接触在右下角
            *
====================  地面 A 静态，法线 n = (0, 1)
```

| 量 | 值 |
|---|---|
| A | 静态，`invMass=0`，`invI=0`，dummy state |
| B | `m=1`，`invMass=1`，`I=0.5`，`invI=2` |
| `n` | `(0, 1)` |
| `rB` | `(0.5, -0.5)` 质心指向接触点 |
| `rA` | 随便，乘 0 |
| 当前 `vB` | `(0, -4)`（往下砸） |
| `wB` | `0` |
| `s` | `−0.02` m（穿透 2cm） |
| `h` | `1/240`，`inv_h=240` |
| 软约束 | `massScale=1`，`impulseScale=0`，`biasRate` 使 `velocityBias = max(9*s, −3) = −0.18` |
| 摩擦 μ | `0.6`（Relax 才用） |
| 恢复 | 0（安静落地） |

### 有效质量

```
cross(rB, n) = rB.x * n.y - rB.y * n.x = 0.5
K = 0 + 1 + 0 + 2 * (0.5)² = 1 + 0.5 = 1.5
normalMass = 1 / 1.5 = 2/3 ≈ 0.6667
```

杆臂让盒子能「转着离开」，所以比「质心正下方接触」（K=1）要「软」一点，同样速度少踹一点。

### 第 1 小步 Solve（useBias = true）

```
vn = -4 + wB * 0.5 = -4
velocityBias = -0.18
λ = -(2/3) * (1 * (-4) + (-0.18)) = (2/3) * 4.18 ≈ 2.787
λ_acc = max(0 + 2.787, 0) = 2.787
```

打出去：

```
P = (0, 2.787)
vB += P = (0, -1.213)
wB += invI * cross(rB, P) = 2 * (0.5 * 2.787) = 2.787
```

`cross(rB, P) = 0.5 * 2.787 - (-0.5) * 0 = 1.393`，`Δw = 2 * 1.393 = 2.787`。盒子一边往上减速，一边逆时针转（右下角被顶）。

再看新的法向相对速度：

```
vn' = vB.y + wB * 0.5 = -1.213 + 2.787 * 0.5 = 0.180
```

刚好顶上 `−velocityBias`：`vn + bias ≈ 0`。**一脚就满足这个点的速度约束**——因为现在只有一个约束。多个接触点、多个盒子时，改 V 会破坏邻居，才需要下一轮/下一小步。

### 积分位置之后

`ΔpB += h * vB`，`ΔqB` 转过 `h * wB`。新的 `s` 会接近 0。下一小步重力再给 `vB.y` 减一点，Solve 再补一脚小冲量。

### Relax 摩擦（同一小步稍后）

法向已经有 `λn = 2.787`。切向：

```
t = RightPerp(n) = (1, 0)
vt = vB.x + wB * cross(rB, t)
cross(rB, t) = 0.5*0 - (-0.5)*1 = 0.5
vt = 0 + 2.787 * 0.5 = 1.393     旋转造成的右滑
```

```
kTangent = 1 + 2 * (0.5)² = 1.5
tangentMass = 2/3
λt = tangentMass * (-vt) = (2/3) * (-1.393) ≈ -0.929
|λt|_max = μ λn = 0.6 * 2.787 ≈ 1.672
|-0.929| < 1.672 → 未饱和，静摩擦，把切向速刹到 0
```

打 `P = λt · t = (-0.929, 0)`：

```
vB.x = -0.929
wB   += 2 * cross(rB, P) = 2 * (0.5*0 - (-0.5)*(-0.929)) = 2 * (-0.465) = -0.929
wB    = 2.787 - 0.929 = 1.858
```

切向速度被吃掉，法向那一脚留下的自旋还在一点。下一小步继续。

### 两轮接触点时发生什么

斜盒子两个点，左边 `λ` 会把速度改到让右边「过约束」，右边再踹回来。顺序冲量就是两边吵架、越吵越轻。热启动让它们从上帧的妥协接着吵，而不是每帧从零开始打架——这就是堆叠稳不稳的分界。

## 四、和「自己推的冲量公式」对上号

教材里常见的对心碰撞：

```
P = -(1 + e) · vn / (1/mA + 1/mB)
```

对应这里：`r = 0`、`K = invMassA + invMassB`、`bias = −e·vn_old`、一次迭代、无软约束。Box2D 多做的是：

- 杆臂 → K 里加上 `I⁻¹ (r×n)²`
- 不等式 → `λ_acc ≥ 0`
- 多个约束 → 顺序扫
- 软约束 → `massScale`、`impulseScale`、Hertz
- 推测 → `s > 0` 时 `bias = s/h`
- 摩擦 → 第二遍、库仑钳制

不是另一套物理，是同一公式长出了工程枝节。

## 五、SIMD 宽版本看什么

`b2PrepareContacts_Wide` / `b2SolveContacts_Wide` 把同一颜色里相邻的 4 或 8 个接触打成 `float` 向量。每个 lane 仍是上面的标量公式。余数不足一宽时，Prepare 把尾巴清零，避免脏 lane 写进某个刚体。

读宽版本的方法：盯一个标量表达式，找同名的 `b2MulW` / `b2MaxW` / `b2BlendW`。`softMask` 用来在动态软度和静态软度之间选。不必先学指令集。

## 六、常见失败对照

| 现象 | 多半是 |
|---|---|
| 落地后抖动 | 没有推测，或 bias 用了 `s/dt` 太大；或恢复阈值太低 |
| 陷进地面 | 和静态接触太软；或只解了速度从未积分前的旧几何 |
| 堆叠倒塌 | 没热启动；`λ` 每帧从 0 开始；或没有子步进 |
| 盒子滑得像冰 | Relax 没做，或 `μ·λn` 用了本帧增量而不是累积 `λn` |
| 斜着弹飞 | 恢复放进了 Solve，和重叠 bias 叠加 |

## 自己写引擎时的最小集

先写一个点、无旋转、无软约束：

```c
float vn = dot(vB - vA, n);
float k  = invMassA + invMassB;
float dPn = -vn / k;                 // 目标 vn = 0
float Pn  = max(accPn + dPn, 0);
dPn = Pn - accPn;
accPn = Pn;
vA -= invMassA * dPn * n;
vB += invMassB * dPn * n;
```

能停在地面后，加 `cross(r,n)`，再加 `max(acc,0)` 跨多个点循环 8 次。热启动 = 下一帧 `accPn` 不要清零。软约束和摩擦放到堆叠已经不塌之后。
