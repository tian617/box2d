# 10 · 累计冲量、摩擦与热启动

[返回总目录](./README.md) · [上一章](./09-碰撞冲量与约束方程.md) · [下一章](./11-软约束子步进与Relax.md)

> 本章解决三个实现问题：为什么夹累计而不是夹增量，如何真正施加热启动，以及摩擦怎样与法向支撑耦合。
> 源码基准：Box2D 3.2.0，提交 `dc67c40ba2ce1ad384b0c985dbc1b539cba9221b`。

## 1. 三个冲量符号不能混用

| 符号 | 含义 | 单位 |
|---|---|---|
| \(\Lambda_{\mathrm{old}}\) | 当前已有的累计冲量估计 | N·s |
| \(d\) | 根据当前残差算出的未经限制修正 | N·s |
| \(\Lambda_{\mathrm{new}}\) | 投影后的新累计 | N·s |
| \(\Delta\Lambda\) | 真正施加到速度上的增量 | N·s |
| \(u\) | 当前相对约束速度 | m/s |
| \(b\) | 速度偏置 | m/s |
| \(K\) | 冲量到相对速度的响应 | kg⁻¹ |

第9章已经得到

\[
d=-\frac{u+b}{K}.
\]

但这个候选还没有满足接触只能推、不能拉的限制。

限制作用于累计量：

\[
\Lambda_{\mathrm{new}}=\max(0,\Lambda_{\mathrm{old}}+d).
\]

真正施加量必须重新计算：

\[
\boxed{\Delta\Lambda=\Lambda_{\mathrm{new}}-\Lambda_{\mathrm{old}}}.
\]

随后才更新缓存并应用冲量。

## 2. 为什么不能把每次增量都夹成非负

“接触不能吸引”要求 \(\Lambda\ge0\)，不要求每次 \(\Delta\Lambda\ge0\)。

先前迭代推多了，就必须能撤回一部分。

| 旧累计 | 候选修正 | 新累计 | 真正施加量 | 含义 |
|---|---|---|---|---|
| 3 | −1 | 2 | −1 | 撤回部分过量冲量 |
| 3 | −5 | 0 | −3 | 最多撤回已有的3 |
| 3 | +1 | 4 | +1 | 只补上缺少的1 |

表中所有数值单位均为N·s。

第一行若错误地执行 \(\max(d,0)\)，修正变成零，永远无法减少过大支撑。

第二行若直接施加候选−5，最终累计变成−2，产生不允许的吸力。

第三行若将新累计 4 整笔再施加，实际施加了 4 N·s，而正确增量只有 1 N·s，因此额外多施加 3 N·s。速度误差还需乘以相应逆质量与角惯量响应，不能把冲量数值直接当作速度。

正确源码把“投影”和“重新算差额”明确分开：

```311:315:src/contact_solver.c
// clamp the accumulated impulse
float newImpulse = b2MaxFloat( cp->normalImpulse + impulse, 0.0f );
impulse = newImpulse - cp->normalImpulse;
cp->normalImpulse = newImpulse;
cp->totalNormalImpulse += impulse;
```

这里最后一行加的是带符号增量，负修正不会被丢掉。

### 2.1 投影在数学上做了什么

记非负半轴投影为

\[
\Pi_{[0,\infty)}(x)=\max(x,0).
\]

顺序求解的一行更新为

\[
\Lambda_i\leftarrow
\Pi_{[0,\infty)}\left(\Lambda_i-\frac{w_i}{K_{ii}}\right),
\qquad w_i=J_i\mathbf V+b_i.
\]

量纲检查：\(w_i/K_{ii}\) 为 \((\mathrm{m/s})/(\mathrm{kg^{-1}})=\mathrm{N\,s}\)。

投影将候选解返回单向接触允许的集合；它不是随意添加的防抖经验值。

一个容易忽略的区别：

- 零累计且正在分离：负候选全部丢弃，不施加吸力。
- 正累计且正在分离：允许减少旧估计，但不能降到零以下。

## 3. 热启动必须让冲量账和速度账一致

仅保存上次 \(\Lambda\)，并不等于已经完成热启动。

若把初始累计猜测设为 \(\Lambda_0\)，速度也必须初始化为

\[
\mathbf V_0=\mathbf V_{\mathrm{free}}+M^{-1}J^T\Lambda_0.
\]

之后施加累计变化 \(\Lambda-\Lambda_0\)，得到

\[
\mathbf V
=\mathbf V_0+M^{-1}J^T(\Lambda-\Lambda_0)
=\mathbf V_{\mathrm{free}}+M^{-1}J^T\Lambda.
\]

这条恒等式就是热启动的正确性账本。

若缓存说已经施加了2N·s，速度里却没有这2N·s的作用，后续投影便建立在错误前提上。

### 3.1 静止支撑的最小算例

A为静态地面，B质量1kg，无转动影响。

本子步外力积分后

\[
v_y=-0.1\ \mathrm{m/s},\qquad K=1\ \mathrm{kg^{-1}}.
\]

历史支撑估计为

\[
\Lambda_0=0.1\ \mathrm{N\,s}.
\]

真正施加缓存后

\[
v_y=-0.1+1(0.1)=0.
\]

本次求解只需

\[
d=-u/K=0.
\]

累计仍为0.1N·s，本子步实际得到的支撑冲量也是0.1N·s。

下一子步重力又使速度下降，再施加上一子步的支撑估计，是为新的时间区间预测支撑，不是重复同一历史事件。

### 3.2 两种不完整热启动

**错误一：保留缓存，却不施加。**

速度仍为−0.1，求解又增加0.1，缓存变0.2，但实际只施加0.1。

**错误二：施加缓存，随后清空累计。**

速度已包含缓存作用，求解器却认为累计为零，不能正确撤回这部分估计。

两者都会使缓存账和速度账分离。

### 3.3 过期缓存必须能撤回

B本来以 \(+0.2\ \mathrm{m/s}\) 离开，旧缓存为0.1N·s。

WarmStart后速度为0.3，候选修正为−0.3。

\[
\Lambda_{\mathrm{new}}=\max(0,0.1-0.3)=0,
\]

\[
\Delta\Lambda=0-0.1=-0.1.
\]

最终速度回到 \(+0.2\ \mathrm{m/s}\)，而非强行变成零。

这正是“缓存预测”和“单向投影”配合的意义。

## 4. Box2D真正施加缓存的位置

Prepare先将跨大步缓存复制到约束副本。

```112:114:src/contact_solver.c
cp->normalImpulse = warmStartScale * mp->normalImpulse;
cp->tangentImpulse = warmStartScale * mp->tangentImpulse;
cp->totalNormalImpulse = 0.0f;
```

之后，每个子步WarmStart都将法向和切向缓存组成冲量并真正作用到速度：

```188:195:src/contact_solver.c
b2Vec2 P = b2Add( b2MulSV( cp->normalImpulse, normal ), b2MulSV( cp->tangentImpulse, tangent ) );

cp->totalNormalImpulse += cp->normalImpulse;

wA -= iA * b2Cross( rA, P );
vA = b2MulAdd( vA, -mA, P );
wB += iB * b2Cross( rB, P );
vB = b2MulAdd( vB, mB, P );
```

本版本有两个需要如实说明的细节：

1. Prepare中的 `warmStartScale` 为0或1；此处没有按新旧时间步比值缩放。
2. 关闭热启动会清掉跨大步种子，但子步WarmStart函数仍被调用，函数内部没有再次跳过开关。

因此不能把“关闭热启动”描述成删除整个子步WarmStart阶段。

## 5. 切向摩擦的方向与速度

本版本使用右垂线：

\[
\mathbf t=\operatorname{RightPerp}(\mathbf n)=(n_y,-n_x).
\]

法线向上 \((0,1)\) 时，切线就是向右 \((1,0)\)。

切向相对速度定义为

\[
u_t=\mathbf t\cdot\mathbf v_{\mathrm{rel}}-v_{\mathrm{belt}}.
\]

其中：

| 量 | 含义 | 单位 |
|---|---|---|
| \(\mathbf v_{\mathrm{rel}}\) | 含旋转的两接触点速度差 | m/s |
| \(v_{\mathrm{belt}}\) | 传送带表面相对目标速度 | m/s |
| \(u_t\) | 相对目标的剩余滑移 | m/s |
| \(\mu\) | 库仑摩擦系数 | 无量纲 |
| \(\Lambda_t\) | 累计切向冲量 | N·s |

将第9章法向推导中的 \(\mathbf n\) 换成 \(\mathbf t\)，得到

\[
K_t=m_A^{-1}+m_B^{-1}
+I_A^{-1}(\mathbf r_A\times\mathbf t)^2
+I_B^{-1}(\mathbf r_B\times\mathbf t)^2.
\]

有效切向质量及无界候选为

\[
m_t=K_t^{-1},\qquad d_t=-m_tu_t.
\]

这一步只回答“停住滑移需要多少冲量”，还没有回答“表面能提供多少冲量”。

## 6. 从库仑力限制推到冲量限制

库仑模型规定

\[
|F_t|\le\mu F_n.
\]

假设本子步 \(\mu\) 不变，对时间积分并使用三角不等式：

\[
\left|\int F_tdt\right|
\le\int|F_t|dt
\le\mu\int F_ndt.
\]

于是

\[
\boxed{|\Lambda_t|\le\mu\Lambda_n}.
\]

两侧均为N·s。

正确切向累计投影为

\[
\Lambda_{t,\mathrm{new}}
=\operatorname{clamp}(\Lambda_{t,\mathrm{old}}-m_tu_t,
-\mu\Lambda_n,+\mu\Lambda_n).
\]

真正应用的仍是差额：

\[
\Delta\Lambda_t=\Lambda_{t,\mathrm{new}}-\Lambda_{t,\mathrm{old}}.
\]

```368:377:src/contact_solver.c
float vt = b2Dot( b2Sub( vrB, vrA ), tangent ) - constraint->tangentSpeed;

// incremental tangent impulse
float impulse = cp->tangentMass * ( -vt );

// clamp the accumulated force
float maxFriction = friction * cp->normalImpulse;
float newImpulse = b2ClampFloat( cp->tangentImpulse + impulse, -maxFriction, maxFriction );
impulse = newImpulse - cp->tangentImpulse;
cp->tangentImpulse = newImpulse;
```

源码注释写 `force`，但此处变量实际是冲量，不能据此误写单位。

摩擦界使用当前累计法向冲量，不是刚才法向求解的增量。

稳定支撑时法向增量可能接近零，累计支撑却不为零；若用增量限幅，接触会错误地失去摩擦。

## 7. 摩擦算例：需要多少与能给多少

取

\[
m_t=0.5\ \mathrm{kg},\quad K_t=2\ \mathrm{kg^{-1}},
\quad u_t=3\ \mathrm{m/s},\quad\Lambda_n=2\ \mathrm{N\,s},\quad\Lambda_{t,old}=0.
\]

无界需求是

\[
d_t=-0.5(3)=-1.5\ \mathrm{N\,s}.
\]

### 7.1 摩擦不足

若 \(\mu=0.4\)，允许范围为

\[
[-\mu\Lambda_n,+\mu\Lambda_n]=[-0.8,+0.8]\ \mathrm{N\,s}.
\]

实际施加−0.8，末滑移为

\[
u_t^+=3+2(-0.8)=1.4\ \mathrm{m/s}.
\]

滑移没有归零，是摩擦能力不足，不是求解器忘记刹车。

### 7.2 摩擦足够

若 \(\mu=1\)，允许范围为±2N·s，候选−1.5合法。

\[
u_t^+=3+2(-1.5)=0.
\]

局部切向约束可以进入黏着状态。

本求解器使用一个摩擦系数与投影，并没有因此实现两套独立的静摩擦系数和动摩擦系数。

### 7.3 法向支撑变小时，旧摩擦也要缩回

旧切向累计为0.6N·s，新法向累计降到0.5N·s，\(\mu=0.4\)。

新摩擦界只有±0.2N·s。

即便当前滑移为零，投影仍需把0.6改为0.2，施加−0.4N·s。

不能仅在 \(u_t\ne0\) 时才检查摩擦限幅。

## 8. 摩擦为什么会重新改变法向速度

法向与切向的交叉响应为

\[
K_{nt}=J_nM^{-1}J_t^T.
\]

因为 \(\mathbf n\cdot\mathbf t=0\)，平动交叉项消失，但转动项一般不消失：

\[
K_{nt}=I_A^{-1}(\mathbf r_A\times\mathbf n)(\mathbf r_A\times\mathbf t)
+I_B^{-1}(\mathbf r_B\times\mathbf n)(\mathbf r_B\times\mathbf t).
\]

沿用右下角接触：

\[
I_B^{-1}=2,\quad\mathbf r_B=(0.5,-0.5),
\quad\mathbf n=(0,1),\quad\mathbf t=(1,0).
\]

得到

\[
K_{nt}=2(0.5)(0.5)=0.5\ \mathrm{kg^{-1}}.
\]

若法向刚解到零，随后切向施加 \(-8/9\ \mathrm{N\,s}\)：

\[
\Delta u_n=K_{nt}\Delta\Lambda_t
=0.5\left(-\frac89\right)=-\frac49\ \mathrm{m/s}.
\]

水平摩擦改变角速度，角速度再改变接触点的竖直速度。

因此“法向先满足，摩擦再满足，所以一遍后两者同时满足”是错误推断。

后续迭代或子步会继续修正这个耦合残差。

## 9. 传送带是在改变表面目标速度

令切线向右，传送带目标为

\[
v_{\mathrm{belt}}=2\ \mathrm{m/s}.
\]

物体接触点当前水平相对速度为零时：

\[
u_t=0-2=-2\ \mathrm{m/s}.
\]

摩擦候选为正，向右推动物体。

若物体接触点已向右运动5m/s：

\[
u_t=5-2=3\ \mathrm{m/s}.
\]

摩擦转而向左，试图回到目标速度2，而不是永远向带子方向加速。

目标能否达到仍受 \(\mu\Lambda_n\) 限制。

本版本将两形状材料的切向速度相加：

```572:572:src/contact.c
contactSim->tangentSpeed = shapeA->material.tangentSpeed + shapeB->material.tangentSpeed;
```

加号来自两侧表面方向约定；不能脱离A/B及切向约定直接改成“世界速度相减”。

## 10. 滚动阻力是一条角速度约束

切向摩擦限制接触点滑动；滚动阻力直接限制相对角速度。

令

\[
u_r=\omega_B-\omega_A.
\]

滚动角冲量 \(\Lambda_r\) 的单位是kg·m²/s，而非N·s。

作用关系为

\[
\Delta\omega_A=-I_A^{-1}\Lambda_r,
\qquad \Delta\omega_B=I_B^{-1}\Lambda_r.
\]

所以

\[
\Delta u_r=(I_A^{-1}+I_B^{-1})\Lambda_r.
\]

定义有效转动惯量

\[
I_{\mathrm{eff}}=\frac1{I_A^{-1}+I_B^{-1}},
\]

无界候选为

\[
d_r=-I_{\mathrm{eff}}(\omega_B-\omega_A).
\]

源码 `rollingMass` 实际具有kg·m²单位；名字里的 `Mass` 不应让人误以为它是线性质量。

### 10.1 滚阻限幅为什么需要长度尺度

本版本限制为

\[
|\Lambda_r|\le\rho\sum_j\Lambda_{n,j}.
\]

右侧法向冲量单位为kg·m/s，左侧为kg·m²/s，因此

\[
[\rho]=\mathrm m.
\]

材料属性的滚阻比例通常无量纲，接触更新先乘形状半径，得到求解器需要的长度参数。

```561:565:src/contact.c
float radiusA = b2GetShapeRadius( shapeA );
float radiusB = b2GetShapeRadius( shapeB );
float maxRadius = b2MaxFloat( radiusA, radiusB );
contactSim->rollingResistance =
	b2MaxFloat( shapeA->material.rollingResistance, shapeB->material.rollingResistance ) * maxRadius;
```

这里半径不是任意包围半径：

- 圆和胶囊返回自己的半径。
- 多边形返回圆角半径 `polygon.radius`。
- 线段等默认返回零。

因此两个零圆角多边形可能即使设置非零材料滚阻，最终接触滚阻仍为零。

### 10.2 滚阻数值例

取 \(I_A=I_B=1\ \mathrm{kg\,m^2}\)、\(\omega_A=0\)、\(\omega_B=2\ \mathrm{rad/s}\)。

\[
I_{\mathrm{eff}}=0.5\ \mathrm{kg\,m^2},\qquad d_r=-1\ \mathrm{kg\,m^2/s}.
\]

材料比例0.1，最大形状半径0.5m，总法向累计4N·s：

\[
\rho=0.1(0.5)=0.05\ \mathrm m,
\qquad\rho\sum\Lambda_n=0.05(4)=0.2\ \mathrm{kg\,m^2/s}.
\]

从零累计开始，实际角冲量只能取−0.2。

\[
\omega_A^+=0.2,\quad\omega_B^+=1.8,\quad u_r^+=1.6\ \mathrm{rad/s}.
\]

滚阻能力不足以本次完全消除相对转动。

## 11. 三种缓存必须分别理解

| 机制 | 缓存什么 | 解决什么问题 |
|---|---|---|
| 接触点ID匹配 | 旧点的法向/切向冲量 | 哪个历史冲量属于新点 |
| 冲量热启动 | 当前约束初始累计估计 | 如何把历史猜测放进当前速度状态 |
| 接触几何回收 | 锚点、法线、相对位姿等 | 是否可跳过本次窄相重算 |

### 11.1 ID匹配不是按数组下标复制

`contact.c:603–655` 先清零新点缓存，再按16位特征ID匹配旧点。

两点数组顺序对调但ID不变时，应按ID迁移。

没有匹配历史的新点，法向和切向冲量从零开始。

### 11.2 几何回收不是另一种冲量投影

`physics_world.c:507–585` 检查相对位姿变化等条件，允许保留旧锚点和法线，只更新分离估计。

这是跳过窄相的几何优化，不是只存下一个冲量数。

回收分支提前 `continue`，还会跳过 `b2UpdateContact` 中的材质刷新及相应PreSolve调用路径。

因此不能承诺修改材料后每个被回收接触都立即刷新；具体回收策略见优化章节。

## 12. Box2D顺序与朴素实现

最朴素实现可以先固定几何，多次扫描法向与摩擦，验证累计投影和动量更新。

**教学伪代码，非项目源码：**

```text
match cached impulses by feature id
apply cached normal, tangent and rolling impulses
for each contact point:
    solve projected accumulated normal impulse
for each contact point:
    solve projected accumulated tangent impulse
```

实际版本则每子步执行：

1. 积分外力速度。
2. WarmStart真正施加缓存。
3. Solve处理法向推测或软穿透修正。
4. 积分位置。
5. Relax先再解法向，然后滚阻，最后摩擦。

摩擦使用Relax法向更新后的累计量，但摩擦之后仍可能留下法向耦合残差。

默认材料混合为 \(\mu=\sqrt{\mu_A\mu_B}\)、\(e=\max(e_A,e_B)\)，可被回调替换，不是动量定理。

例如 \(\mu_A=0.25,\mu_B=1\) 得 \(\mu=0.5\)；任意一侧为零时默认混合摩擦为零。
