# 12 · 接触求解器逐行导读与完整算例

[返回总目录](./README.md) · [上一章：软约束、子步进与Relax](./11-软约束子步进与Relax.md)

> 本章将前面三章的公式逐项对应到标量接触求解器，并完整计算一个子步。
> 源码基准：Box2D 3.2.0，提交 `dc67c40ba2ce1ad384b0c985dbc1b539cba9221b`。
> 数值使用独立双精度计算复核，不代表已经运行C仿真测试；源码float及FMA可能造成末位差异。

## 1. 先画清楚数据的生命周期

| 数据 | 保存什么 | 何时变化 |
|---|---|---|
| `manifold` | 接触几何、特征ID、缓存冲量、速度历史 | 窄阶段更新，整步末提交冲量 |
| `constraint` | 本大步求解副本、有效质量、当前累计冲量 | Prepare一次，子步反复更新 |
| `bodyState` | 当前速度、相对大步开始的位姿增量 | 积分与约束求解 |
| `context` | 子步长度、软度、索引、阶段参数 | 大步组织时准备 |

读每一条赋值，先判断它属于以下哪类：

1. 从历史复制初始猜测。
2. 初始化本大步统计。
3. 真正改变物理速度或位置。
4. 向下一大步提交结果。

“保留冲量就是热启动”“恢复在Prepare现算”“总冲量就是最后累计”都源于混淆这些生命周期。

## 2. Prepare：把接触整理成求解数据

入口：[`b2PrepareContacts_Overflow`](../src/contact_solver.c#L24-L138)。

### 2.1 24–77行：选择接触与复制公共属性

| 行区间 | 表达式或对象 | 应怎样理解 |
|---|---|---|
| 24–33 | world、graph、Overflow数组 | 选择待求解接触，不在这里检测碰撞 |
| 35–65 | 验证bodySim索引 | 检查索引是否仍对应awake状态 |
| 39–43 | 普通/静态软度、warmStartScale | 缓存种子是否乘0或1 |
| 69–71 | `indexA + 1`、`indexB + 1` | 存储索引以0代表null |
| 72–77 | normal、friction、rolling、tangentSpeed | 接触共有数据，而不是每点单独一份 |

滚动冲量是整个manifold共用的角冲量，不应为每个点重复存一份同样滚阻。

### 2.2 79–105行：逆质量与方向

局部变量 `mA`、`mB` 存的是逆质量，`iA`、`iB` 存的是逆惯量。

\[
[m_A^{-1}]=\mathrm{kg^{-1}},\qquad[I_A^{-1}]=\mathrm{(kg\,m^2)^{-1}}.
\]

84–91行按任意一侧状态索引是否null选择静态软度。

运动学体也可能逆质量为零但拥有状态，不能只按逆质量零来复刻这个判断。

100–101行计算

\[
I_{eff,r}=\frac1{I_A^{-1}+I_B^{-1}}.
\]

这就是 `rollingMass`，单位kg·m²；分母为零时取零。

104–105行保留法线并构造右垂线作为切线。

### 2.3 107–133行：每点准备

```112:121:src/contact_solver.c
cp->normalImpulse = warmStartScale * mp->normalImpulse;
cp->tangentImpulse = warmStartScale * mp->tangentImpulse;
cp->totalNormalImpulse = 0.0f;

b2Vec2 rA = mp->anchorA;
b2Vec2 rB = mp->anchorB;

cp->anchorA = rA;
cp->anchorB = rB;
cp->baseSeparation = mp->separation - b2Dot( b2Sub( rB, rA ), normal );
```

这十行分别完成：

1. 载入跨大步法向、切向初始猜测。
2. 清零本大步实际冲量统计，而不是把两个累计猜测一起清空。
3. 保留大步开始的世界方向质心杆臂。
4. 为位姿增量分离公式构造基准。

这里

\[
s_{base}=s_0-\mathbf n\cdot(\mathbf r_B-\mathbf r_A).
\]

它不同于几何回收路径中的 `mp.baseSeparation`。

`physics_world.c:619` 给manifold基准直接保存当时分离；同名字段不能跨结构体互换公式。

123–131行计算法向和切向有效质量：

\[
K_n=m_A^{-1}+m_B^{-1}
+I_A^{-1}(\mathbf r_A\times\mathbf n)^2
+I_B^{-1}(\mathbf r_B\times\mathbf n)^2,
\qquad m_n=1/K_n.
\]

切向仅将 \(\mathbf n\) 换成 \(\mathbf t\)。

最后一项只是复制：

```133:133:src/contact_solver.c
cp->restitutionVelocity = mp->restitutionVelocity;
```

这里没有读取当前刚体速度、没有乘恢复系数，也没有检查恢复阈值。

## 3. WarmStart：真正把缓存打进速度

入口：[`b2WarmStartContacts_Overflow`](../src/contact_solver.c#L140-L215)。

149–163行读取awake状态数组，静态侧使用单位dummy状态。

这个状态给出零速度、零位移增量和单位旋转。

165–178行将速度、逆质量、法线、切线读到局部变量。

180–195行逐点构造并施加

\[
\mathbf P=\Lambda_n\mathbf n+\Lambda_t\mathbf t.
\]

法向与切向都是线冲量，能够合成二维向量。

```188:195:src/contact_solver.c
b2Vec2 P = b2Add( b2MulSV( cp->normalImpulse, normal ), b2MulSV( cp->tangentImpulse, tangent ) );

cp->totalNormalImpulse += cp->normalImpulse;

wA -= iA * b2Cross( rA, P );
vA = b2MulAdd( vA, -mA, P );
wB += iB * b2Cross( rB, P );
vB = b2MulAdd( vB, mB, P );
```

190行将本次实际施加的法向缓存计入大步统计。

每点都立即改变局部速度，下一点会看到变化。

198–199行另外施加滚动角冲量，只改角速度，不应把它混进二维 \(\mathbf P\)。

201–211行仅将动态刚体的局部速度写回。

运动学体可以贡献给定速度，但不由接触冲量加速；静态dummy也不写回为真实动态物体。

## 4. Solve与Relax共用同一个函数

入口：[`b2SolveContacts_Overflow`](../src/contact_solver.c#L217-L402)。

### 4.1 229–265行：读取当前子步状态

| 数据 | 含义 |
|---|---|
| `inv_h` | 子步长度倒数，不是整步倒数 |
| `contactSpeed` | 穿透速度偏置的夹限尺度 |
| `vA,wA,vB,wB` | 当前已经经历外力、缓存及前序约束的速度 |
| `dqA,dqB` | 相对大步开始的累计旋转 |
| `dp` | 双方累计位移增量之差 |
| 局部 `totalNormalImpulse` | 本次各点最终法向累计之和，仅供滚阻限幅 |

最后一项不同于每点字段 `cp.totalNormalImpulse` 的跨子步统计。

### 4.2 271–294行：当前分离与三种偏置情况

几何分离采用

\[
s=s_{base}+\mathbf n\cdot[
\Delta\mathbf p_B-\Delta\mathbf p_A
+R(\Delta q_B)\mathbf r_B-R(\Delta q_A)\mathbf r_A].
\]

这里旋转杆臂用于估计几何分离；之后点速度和力矩仍使用固定杆臂。

| 分支 | 条件 | bias | scale |
|---|---|---|---|
| 推测 | \(s>0\) | \(s/h\) | 硬基线1、0 |
| 穿透软修正 | \(s\le0\)，Solve | 夹限后的软偏置 | MakeSoft系数 |
| 无重叠偏置 | \(s\le0\)，Relax | 初始为0 | 硬基线1、0 |

因此 `useBias=false` 并不会关闭正间隙的推测bias。

### 4.3 296–305行：点速度和恢复目标

点速度为

\[
\mathbf v_{rA}=\mathbf v_A+\omega_A\times\mathbf r_A,
\quad\mathbf v_{rB}=\mathbf v_B+\omega_B\times\mathbf r_B,
\]

\[
u_n=(\mathbf v_{rB}-\mathbf v_{rA})\cdot\mathbf n.
\]

仅Relax且恢复目标为正时，执行

\[
b\leftarrow\min(b,-v_{rest}).
\]

正恢复目标通过负bias实现。

`stopRestitution` 只对具有正恢复目标的点更新AND。

严谨说法是：所有仍有正恢复目标的点均已分离时，当前约束副本的恢复目标会清零。

没有恢复目标的点，不会阻止这次清除。

### 4.4 308–328行：法向增量、投影、应用

```308:315:src/contact_solver.c
// incremental normal impulse
float impulse = -cp->normalMass * ( massScale * vn + velocityBias ) - impulseScale * cp->normalImpulse;

// clamp the accumulated impulse
float newImpulse = b2MaxFloat( cp->normalImpulse + impulse, 0.0f );
impulse = newImpulse - cp->normalImpulse;
cp->normalImpulse = newImpulse;
cp->totalNormalImpulse += impulse;
```

逐项翻译：

1. 用当前速度、偏置和旧累计算候选增量。
2. 将累计限制到非负。
3. 重算真正能施加的差额。
4. 更新本子步累计。
5. 将有符号差额计入大步统计。

319–320行把新累计加入滚阻的本次法向汇总。

322–328行应用 \(\Delta\mathbf P=\Delta\Lambda_n\mathbf n\)，A减B加，并改变角速度。

### 4.5 331–384行：只在Relax执行

先处理恢复终止，再处理滚阻，最后处理所有点摩擦。

滚阻为

\[
d_r=-I_{eff,r}(\omega_B-\omega_A),
\quad |\Lambda_r|\le\rho\sum_j\Lambda_{n,j}.
\]

摩擦读取滚阻已经修改后的速度：

\[
u_t=(\mathbf v_{rB}-\mathbf v_{rA})\cdot\mathbf t-v_{belt},
\quad d_t=-m_tu_t,
\quad |\Lambda_t|\le\mu\Lambda_n.
\]

两者都投影累计并仅施加差额。

摩擦会通过角速度改变法向速度；这一函数不会在每点摩擦之后自动再解一次法向。

388–398行将最终局部速度写回动态状态。

```428:431:src/contact_solver.c

mp->normalImpulse = constraint->points[j].normalImpulse;
mp->tangentImpulse = constraint->points[j].tangentImpulse;

```

434–447行检查hit事件，要求启用事件，并同时满足

\[

\]

有manifold点不等于真的发生了撞击；推测接触可能从未产生实际净法向作用。

Store没有写回 `normalVelocity`，也没有写回约束副本的 `restitutionVelocity`。

## 6. 完整数值算例：先列清所有输入

本例先使用便于手算的教学bias，随后替换为真实MakeSoft参数。

| 项目 | 数值或条件 |
|---|---|
| A | 静态，逆质量与逆惯量均零 |
| B质量 | \(m=1\)kg |
| B惯量 | \(I=0.5\)kg·m² |
| 法线、切线 | \(\mathbf n=(0,1),\mathbf t=(1,0)\) |
| 杆臂 | \(\mathbf r_A=(0,0),\mathbf r_B=(0.5,-0.5)\)m |
| 初始速度 | \(\mathbf v_B=(0,-4)\)m/s，\(\omega_B=0\) |
| 初始分离 | \(s_0=-0.02\)m |
| 子步长度 | \(h=1/240\)s |
| 摩擦系数 | \(\mu=0.6\) |
| 滚阻、恢复目标 | 均为零 |
| 缓存冲量 | 均为零 |
| 本子步外力、重力、阻尼 | 均为零，用于隔离接触计算 |
| 运动锁与限速 | 没有锁定，不触发限速 |
| 初始位姿增量 | 位移零，旋转单位 |

惯量是独立给定的教学数据，不声称它等于边长1m均匀方盒的真实惯量。

教学软度取 `massScale=1`、`impulseScale=0`、`biasRate=9`，`contactSpeed=3`。

这个组合用于方便手算，不是假称默认 `b2MakeSoft` 精确返回这些值。

### 6.1 Prepare

\[
\mathbf r_B\times\mathbf n
=\mathbf r_B\times\mathbf t=0.5\ \mathrm m.
\]

\[
K_n=K_t=1+2(0.5)^2=1.5\ \mathrm{kg^{-1}},
\quad m_n=m_t=\frac23\ \mathrm{kg}.
\]

\[
s_{base}=-0.02-(-0.5)=0.48\ \mathrm m.
\]

滚动有效惯量为0.5kg·m²，但滚阻上限为零，因此不会施加滚阻。

### 6.2 积分速度与WarmStart

本例外力为零，积分速度后仍为 \((0,-4)\)、\(\omega=0\)。

缓存也为零，WarmStart不改速度，本步总冲量统计仍为零。

### 6.3 Solve法向

初始位姿增量为单位状态，所以

\[
s=0.48-0.5=-0.02\ \mathrm m.
\]

教学bias为

\[
b=\max(9(-0.02),-3)=-0.18\ \mathrm{m/s}.
\]

初始 \(u_n=-4\)，因此

\[
\Delta\Lambda_n=-\frac23(-4-0.18)
=\frac{209}{75}
\approx2.7866666667\ \mathrm{N\,s}.
\]

投影不截断，应用后

\[
v_y=-4+\frac{209}{75}=-\frac{91}{75}\approx-1.2133333333,
\]

\[
\omega=2\left(0.5\frac{209}{75}\right)
=\frac{209}{75}\approx2.7866666667.
\]

校验接触点法向速度：

\[
u_n=v_y+0.5\omega=0.18\ \mathrm{m/s}.
\]

此时切向速度为 \(u_t=0.5\omega=1.3933333333\ \mathrm{m/s}\)。

### 6.4 积分位置：不能跳过这一步

\[
\Delta y=hv_y=\frac1{240}\left(-\frac{91}{75}\right)
=-0.005055555555556\ \mathrm m.
\]

传入旋转积分的参数为

\[
\delta=h\omega=0.0116111111111111.
\]

本版旋转积分不是直接精确求 \(\sin\delta,\cos\delta\)，而是归一化Euler结果。

```394:398:include/box2d/math_functions.h
b2Rot q2 = { q1.c - deltaAngle * q1.s, q1.s + deltaAngle * q1.c };
float mag = sqrtf( q2.s * q2.s + q2.c * q2.c );
float invMag = mag > 0.0f ? 1.0f / mag : 0.0f;
b2Rot qn = { q2.c * invMag, q2.s * invMag };
return qn;
```

由初始单位旋转得到

\[
\Delta q=\frac{(1,\delta)}{\sqrt{1+\delta^2}}
\approx(0.999932597864567,0.0116103284974275).
\]

旋转后的杆臂为

\[
R(\Delta q)\mathbf r_B
\approx(0.505771463180997,-0.494161134683570)\ \mathrm m.
\]

所以更新分离为

\[
s=0.48-0.005055555555556-0.494161134683570
\approx-0.0192166902391253\ \mathrm m.
\]

它仍为负，因此接下来的Relax不会走正间隙推测分支。

### 6.5 Relax必须先重新解法向

点速度使用固定杆臂，当前法向速度仍为0.18m/s。

无恢复目标、仍穿透时，Relax采用 \(b=0\)、两个scale为1和0。

\[
\Delta\Lambda_n=-\frac23(0.18)=-0.12\ \mathrm{N\,s}.
\]

新累计为

\[
\Lambda_n=\frac{209}{75}-0.12=\frac83\ \mathrm{N\,s}.
\]

速度变成

\[
v_y=-\frac43,\qquad\omega=\frac83,
\qquad u_n=0,\qquad u_t=\frac43.
\]

负修正也从总冲量统计中扣除。

这一步不能省略，否则后面的摩擦数值会错成约−0.929。

### 6.6 Relax滚阻

滚阻系数为零，累计角冲量从零投影到零。

虽然物体仍在旋转，但本例不施加任何滚阻角冲量。

### 6.7 Relax摩擦

\[
d_t=-m_tu_t=-\frac23\frac43=-\frac89\ \mathrm{N\,s}.
\]

允许的摩擦界为

\[
\mu\Lambda_n=0.6\frac83=1.6\ \mathrm{N\,s}.
\]

候选没有超界，因此切向累计为 \(-8/9\)。

平动与转动更新：

\[
v_x=-\frac89,
\qquad\Delta\omega=2\left[0.5(0)-(-0.5)\left(-\frac89\right)\right]
=-\frac89.
\]

最终

\[
\boxed{\mathbf v_B=(-8/9,-4/3)\ \mathrm{m/s},\qquad\omega_B=16/9\ \mathrm{rad/s}}.
\]

检查两个方向：

\[
u_t=-\frac89+0.5\frac{16}{9}=0,
\]

\[
\boxed{u_n=-\frac43+0.5\frac{16}{9}=-\frac49\ \mathrm{m/s}}.
\]

切向满足后，法向又产生接近残差。

因为 \(K_{nt}=0.5\ \mathrm{kg^{-1}}\)，摩擦使法向速度改变 \(0.5(-8/9)=-4/9\)。

这是真实耦合，不应谎称一遍后两个方向都严格满足。

固定几何、硬约束并反复迭代的对照解为

\[
\begin{pmatrix}1.5&0.5\\0.5&1.5\end{pmatrix}
\begin{pmatrix}\Lambda_n\\\Lambda_t\end{pmatrix}
=\begin{pmatrix}4\\0\end{pmatrix},
\qquad\Lambda_n=3,\quad\Lambda_t=-1.
\]

此时 \(\mathbf v=(-1,-1),\omega=2\)，两个点速度分量都为零，且 \(|\Lambda_t|\le0.6\Lambda_n\)。

这是耦合联立解标尺，不是声称本版本一遍Solve/Relax已经达到它。

| 更新后分离 | −0.0190290998759322 m |

冲量计算为

\[
\Delta\Lambda_n=-\frac23[0.971333010129369(-4)-0.339518219271798]
=2.816566839859516.
\]

Relax法向修正为

\[
\Delta\Lambda_{relax}=-\frac23(0.224850259789273)
=-0.149900173192849.
\]

累计再次到达 \(8/3\)，随后摩擦仍为 \(-8/9\)，**第一个子步 Relax 结束时**的速度与教学例相同。这里没有继续算余下三个子步，不能把它当成四子步大步的最终结果。

但本子步位置推进和分离估计不同；同一阶段速度相同不等于全过程相同。

30Hz普通软度只能作为非静态软度对照：

\[
b\approx-0.170904080033821,\quad
\Lambda_{solve}\approx2.626680909548488,\quad
u_{solve}\approx-0.0599786356772674.
\]

这时Relax反而补上 \(+0.0399857571181782\)N·s。

## 9. 恢复目标来自上一大步，而非Prepare现算

普通更新在 `contact.c:529` 保存旧manifold，再生成新几何。

新点按ID匹配历史，只有匹配点才有相应旧速度和冲量证据。

```643:645:src/contact.c
if ( mp1->totalNormalImpulse > 0.0f && mp1->normalVelocity < -world->restitutionThreshold )
{
	mp2->restitutionVelocity = -contactSim->restitution * mp1->normalVelocity;
```

时间顺序为：

1. 用旧 `totalNormalImpulse` 和旧 `normalVelocity` 决定本次恢复目标。
2. 在 `physics_world.c:638` 记录本次窄阶段的接近速度。
3. 之后才进行本步积分速度、WarmStart和约束求解。
4. Store只提交冲量，不重写这次采样的 `normalVelocity`。

回收路径在 `physics_world.c:551–576` 保持同样“先用旧历史，再记录当前速度”的顺序。

| 大步 | 几何与历史 | 恢复行为 |
|---|---|---|
| \(k\) | 新ID，无匹配旧点；记录速度−4m/s | 初始恢复目标为0 |
| \(k\)求解后 | 产生正总法向冲量 | 留下实际作用证据 |
| \(k+1\) | ID持续，\(e=0.5\)，阈值1m/s | 由旧速度−4生成目标+2m/s |
| \(k+1\)Relax | 使用已复制目标 | bias取−2以求恢复 |
| \(k+2\) | 再检查 \(k+1\) 新历史 | 不应无限复用最早的−4 |

因此本版本不是“首次发现接触时在Prepare用当前速度立刻计算同帧反弹”的最简教科书实现。

源码也明确说明恢复取上一时间步接近速度，并非高精度恢复系数实验模拟器。

## 10. `totalNormalImpulse` 的准确含义

Prepare令 \(T_n=0\)。

每子步WarmStart加初始累计；每次Solve/Relax再加有符号增量。

该子步贡献为

\[
\Lambda_{in}+\sum\Delta\Lambda=\Lambda_{out}.
\]

全部子步完成后

\[
\boxed{T_n=\sum_{k=1}^{N}\Lambda_{out,k}}.
\]

所以它不是：最后增量、最后累计、历史最大值，或只累加正增量的统计。

它包含WarmStart和恢复的作用，也包含撤回冲量的负增量。

例：水平地面上 1 kg 物体稳定静止，全部重量由一个无转动耦合的接触点承担，\(g=10\)m/s²、\(h=1/240\)s、四子步。若由多个点共同支撑，下式的冲量应解释为这些支撑点的合计：

\[
\Lambda_{out,k}\approx mgh=\frac1{24}\ \mathrm{N\,s},
\quad T_n\approx4\frac1{24}=\frac16\ \mathrm{N\,s}.
\]

大步平均法向力是

\[
\boxed{\bar F_n=T_n/\Delta t=(1/6)/(1/60)=10\ \mathrm N}.
\]

整步总量不能除以子步 \(h\)，否则得到40N。

末子步累计 \(\Lambda_{out,N}/h\) 可以估计末子步平均法向力，但它与整步统计是不同用法。
