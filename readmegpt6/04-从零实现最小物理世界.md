# 04 · 从零实现最小物理世界

[返回总目录](./README.md)

本章不是把 Box2D 换个名字重新抄一遍，而是建立一个能不断增加功能、每一步都能验证的教学引擎。
先做正确的单线程版本；只有测量显示性能不足，才添加树、睡眠、数据拆分、并行和 SIMD。
力和积分的示意图见第 03 章，圆与 AABB 见第 05 章，多边形 SAT 见第 06 章，距离查询见第 07 章，冲量公式见第 09 章。本章只把它们按可验证的顺序串起来。
本章所有普通代码围栏均为教学伪代码，不是可编译程序，也不是当前 Box2D API 调用示例。
真实源码引用使用带行号和文件路径的专用格式。

## 1. 第一份设计只回答四个问题

1. 当前世界保存哪些状态？
2. 一个时间步读取什么输入？
3. 每个阶段允许修改哪些状态？
4. 怎样判断这一步的结果对不对？

如果无法回答第3点，就很容易把力清零、碰撞冲量和位置更新放错时机。
如果无法回答第4点，画面“看着差不多”会掩盖符号、尺度和能量错误。

## 2. 最小状态表：先不要复制全部内部结构

| 字段 | 含义 | 单位 | 生命周期 |
|---|---|---|---|
| `type` | 静态、动态、运动学 | 枚举 | 通常长期保持 |
| `center` | 世界质心位置 | m | 每步更新 |
| `rotation` | 单位旋转二元组 | 无量纲 | 每步更新 |
| `linearVelocity` | 质心线速度 | m/s | 外力和冲量改变 |
| `angularVelocity` | 角速度 | rad/s | 力矩和冲量改变 |
| `force` | 本大步待积分合力 | N | 大步收尾清零 |
| `torque` | 本大步待积分合力矩 | N·m | 大步收尾清零 |
| `invMass` | 逆质量 | 1/kg | 形状或质量改变时更新 |
| `invInertia` | 逆质心惯量 | 1/(kg·m²) | 质量或旋转锁改变时更新 |
| `localCenter` | 质心相对刚体原点 | m | 质量分布改变时更新 |
| `shape` | 圆半径或局部顶点 | m | 通常长期保持 |

最初只有圆时，可以将圆心同时作为刚体原点和质心，令 `localCenter=0`。
这只是 M1/M2 的简化，不是一般刚体永远满足的定律。
静态物体不移动、不接受力和冲量响应。
运动学物体按给定速度移动，但不因力和碰撞冲量改变速度。
动态物体由动力学推进，质量应为正。
因此后面加入运动学物体时，不能只用 `invMass==0` 跳过所有位置积分。

对应源码的结构不是一份大结构，而是分开组织的。
`b2BodyState` 保留高频速度和增量，见 [刚体内部结构](../src/body.h)，153–169行。
`b2BodySim` 保留变换、质心、力、逆量等，见175–209行。
教学阶段先合并存放，等访问热点明确后再拆分。

## 3. 固定步长：物理时间不等于渲染帧时长

先取物理步长 \(h=1/60\,s\)。
显示器可以每秒144帧，也可能某帧卡顿；物理仍以固定 h 推进。
累积器的含义是：现实经过的时间暂存起来，够一个 h 才推进一次物理。

```text
accumulator += elapsedRealTime
steps = 0
while accumulator >= h and steps < stepBudget:
    StepPhysics(h)
    accumulator -= h
    steps += 1
alpha = clamp(accumulator / h, 0, 1)
renderFromKnownStates(alpha)
```

`stepBudget` 防止一次卡顿后无限补步拖垮后续帧。
这份教学伪代码选择保留未处理的物理时间积压，只将渲染插值系数钳在 0～1：例如积压为 \(2h\)，原始比例为 2，钳制后为 1，显示最新已知状态而不对未知未来外推。它不修改累积器，因此没有暗中丢弃待模拟时间。
到达预算后也可另选丢弃部分时间，但会牺牲实时一致性；保留积压则会使模拟落后。
不能一边丢弃时间，一边宣称完整模拟了全部真实经过的秒数。
用于渲染的插值不应写回物理状态。
初期不需要插值，直接绘制最新物理状态即可。
验收时按固定步数测试，而不是根据主观经过了“差不多一秒”。

## 4. M1：只有质心、重力和积分

### 4.1 输入和输出

输入是上一步 \((x_n,v_n)\)、质量 m、外力 F、重力 g、步长 h。
输出是新状态 \((x_{n+1},v_{n+1})\)。
先不加碰撞、阻尼、睡眠和速度限制，以便与第03章的手算结果逐项比较。

```text
for each dynamic body:
    acceleration = invMass * force + gravity
    linearVelocity += h * acceleration
for each dynamic body:
    center += h * linearVelocity
for each body:
    force = zero
    torque = zero
```

这是 N=1 的版本，力在完整大步结束时清零。
后面加子步时要把清零移到子步循环外，不能保留在每个子步中。

### 4.2 验收数据必须精确到具体方法

\(y_0=10\)、\(v_0=0\)、\(g=-10\)、\(h=1/60\)，走60步。
半隐式欧拉应约为 \(y=4.916667\)、\(v_y=-10\)。
显式欧拉应约为 \(y=5.083333\)，解析解为5。
这里不允许启用地板，否则测试对象已不再是纯自由落体。
若 y 一直不变，检查是否漏掉位置写回或时间步为零；不要把它直接归咎于显式欧拉。

### 4.3 临时地板只是一块脚手架

可以暂时令圆心高度不得小于半径 R，并在下穿时把竖直速度置零。
必须写明这是占位逻辑，不是一般碰撞求解。
它不能守恒两物体碰撞动量，不能处理斜面、运动地板、恢复系数和旋转。
M1验收通过后立即用 M2 替换，不要围绕它堆更多特例。
对应：[求解器](../src/solver.c)，`b2IntegrateVelocitiesTask` 66–112行；`b2IntegratePositionsTask` 114–162行。

## 5. M2：先用最容易看懂的离散圆碰撞

教学第一版可采用：积分速度 → 积分位置 → 检测当前重叠 → 施加碰撞冲量 → 有界位置修正。
这是简单的离散后处理流程，不是当前 Box2D 的完整阶段顺序。
它只检查离散时刻，高速圆可能跨过彼此而未被检测；后面需更小步长、推测接触或 CCD。
将这种限制写清，比一开始隐含承诺“不会穿透”更重要。

### 5.1 暴力配对足够开始

```text
for i from 0 to bodyCount - 1:
    for j from i + 1 to bodyCount - 1:
        skip incompatible pair types
        generateCircleContact(i, j)
```

只用 \(j>i\)，避免重复求解 A-B 和 B-A。
全部不同物体对数量为：

\[
N_{pairs}=\frac{n(n-1)}2.
\]

10个物体只有45对，100个有4950对，2000个有1999000对。
这直接说明为什么初期暴力法足够，而规模大后需要宽阶段。
宽阶段只筛候选，不能把 AABB 重叠当成精确几何接触。

### 5.2 圆与圆的几何输出

设圆心 \(C_A,C_B\)，半径 \(R_A,R_B\)。

\[
d=C_B-C_A,
\quad D=\lVert d\rVert,
\quad n=d/D,
\quad s=D-R_A-R_B.
\]

n 从 A 指向 B，无量纲且长度为1。
s 单位米：正数表示间隙，零表示刚好接触，负数表示重叠。
表面上的两点为：

\[
Q_A=C_A+R_An,
\qquad
Q_B=C_B-R_Bn.
\]

教学接触点可取 \(P=(Q_A+Q_B)/2\)。
圆心距离为1.8米、两半径都为1米，则 \(s=-0.2\,m\)。
n方向不能因求解阶段切换而随意反转，否则所有冲量正负号都会失效。

若 D 为零，法线未定义。
初版可拒绝完全同心的初始圆，或使用固定顺序下的备用法线并明确这是教学策略。
当前 `b2CollideCircles` 调用的归一化函数在零差值时返回零向量，不应声称源码自动选好了任意有效法线。
定位：[流形生成](../src/manifold.c)，`b2CollideCircles`，36–64行。
本版还可在正间隙小于推测距离时生成流形，并非必须重叠才存在接触数据。

## 6. 一次法向冲量，从目标速度推出来

在暂不考虑圆的切向摩擦和旋转响应时：

\[
v_n=(v_B-v_A)\cdot n.
\]

因为 n 从 A 指向 B，所以 \(v_n<0\) 表示接近，\(v_n>0\) 表示分离。
恢复系数 \(e\in[0,1]\) 定义目标：

\[
v_n^+=-e\,v_n^-.
\]

上标减号和加号表示碰撞前、碰撞后，不是取绝对正负。
施加标量冲量 j，对 A 为 \(-jn\)，对 B 为 \(+jn\)：

\[
v_A^+=v_A^--m_A^{-1}jn,
\qquad
v_B^+=v_B^-+m_B^{-1}jn.
\]

相减后沿 n 投影，利用 \(n\cdot n=1\)：

\[
v_n^+=v_n^-+(m_A^{-1}+m_B^{-1})j.
\]

代入恢复目标：

\[
j=-\frac{(1+e)v_n^-}{m_A^{-1}+m_B^{-1}}.
\]

分子为米每秒，分母为每千克，j单位为千克·米每秒，即冲量。
初版只在接近时求这个碰撞冲量；分母为零时必须跳过或拒绝不可响应约束。
已经分离的重叠物体，可以仍做位置修正，但不应为了“有重叠”再给一个吸引冲量。

### 6.1 等质量的完整手算

两圆质量均为2千克，水平法线 \(n=(1,0)\)。
碰撞前 \(v_A=3\)、\(v_B=-1\)，相对法向速度 \(v_n=-4\)。
逆质量和 \(K=0.5+0.5=1\)。
当 \(e=1\)，\(j=8\,N\cdot s\)。
碰撞后 \(v_A=3-0.5(8)=-1\)，\(v_B=-1+0.5(8)=3\)，交换速度。
总动量碰前碰后均为4，动能均为10焦耳。
当 \(e=0\)，\(j=4\)，两者速度都变成1。
总动量仍为4，动能降为2焦耳，损失8焦耳。
因此恢复系数0不是“所有世界速度都清零”，而是法向相对速度消失。

### 6.2 静态地面例子

令 A 为静态地面，n向上；B质量2千克，速度向下3米每秒。
\(K=0+0.5=0.5\)，\(e=0\)，所以 \(j=6\,N\cdot s\)。
B速度增加 \(0.5\times6=3\,m/s\)，变为0。
静态地面是外部固定支撑；只统计动态物体时，动量不必守恒，因为环境接收了反作用。

## 7. 位置重叠与速度接近是两个问题

冲量改速度，不会自动把已经重叠的位置分开。
教学初版可使用有界、按逆质量加权的位置投影。
令容许重叠为 \(\sigma\ge0\)，修正比例为 \(\beta\in(0,1]\)：

\[
p=\max(-s-\sigma,0),
\qquad K=m_A^{-1}+m_B^{-1}.
\]

这里 p 是要处理的穿透深度，单位米；\(\sigma\) 避免微小误差反复修正。
当 \(K>0\)：

\[
\Delta C_A=-\frac{m_A^{-1}}K\beta p\,n,
\qquad
\Delta C_B=+\frac{m_B^{-1}}K\beta p\,n.
\]

质量较小的对象移动较多，静态对象逆质量为零所以完全不动。
例：两物体质量都2，\(s=-0.025\,m\)、\(\sigma=0.005\,m\)、\(\beta=0.2\)。
p=0.02米，总分离增加0.004米，各移动0.002米。
这只是位置纠偏，并不等价于真实弹性碰撞；过度修正会导致跳变和能量问题。
到稳定约束阶段，应明确选择位置纠偏、速度偏置或更完整约束策略，不要同时无节制叠加。

## 8. M3：让圆变成能转动的盒子

矩形先用局部顶点 \((-a,-b),(a,-b),(a,b),(-a,b)\) 表示。
a、b为半宽半高，单位米。
按第01章公式，将局部点变到世界：\(P=p+Rv_l\)。
按第02章计算质量和质心惯量。
按第03章积分角速度和姿态。
碰撞点相对质心的力臂为 \(r_A=P-C_A\)、\(r_B=P-C_B\)。

接触点速度不再只是质心速度：

\[
u_A=v_A+\omega_A\times r_A,
\qquad
u_B=v_B+\omega_B\times r_B.
\]

相对法向速度为 \(v_n=(u_B-u_A)\cdot n\)。
冲量除了改线速度，还必须改角速度：

\[
\Delta\omega_A=-I_A^{-1}(r_A\times jn),
\qquad
\Delta\omega_B=+I_B^{-1}(r_B\times jn).
\]

因此有效逆质量变为：

\[
K_n=m_A^{-1}+m_B^{-1}
+I_A^{-1}(r_A\times n)^2
+I_B^{-1}(r_B\times n)^2.
\]

平方来自：冲量先经力臂产生角速度，再由角速度经同一力臂反馈到接触点法向速度。
每个转动项的单位都是每千克，与平动逆质量一致。
漏掉它就等于假定偏心冲量不会通过转动改变接触点速度。
定位：[接触准备](../src/contact_solver.c)，`b2PrepareContacts_Overflow`，116–131行。

## 9. 区分几何触地、流形候选点与实际支撑

先做盒子对水平地面，可以计算每个顶点到地面有符号距离。
再推广到凸多边形 SAT、参考边、入射边和裁剪。
SAT用于寻找分离轴或参考面，完整流形生成还需要确定接触点，不能只输出“碰撞/不碰撞”。
有效流形通常包含1或2个点，但候选点数量不等于当前几何触地点数量，也不等于产生正法向冲量的点数。

例如半宽1、半高0.5的盒子逆时针倾斜20度。
两个底角相对质心的 y 坐标分别为：

\[
y_L=-\sin20^\circ-0.5\cos20^\circ\approx-0.811866,
\]

\[
y_R=+\sin20^\circ-0.5\cos20^\circ\approx-0.127826.
\]

当左下角刚好接触地面时，右下角仍高约0.68404米。
较高角尚未几何触地，但这不等于流形必须删除较高点。当前 `b2ClipPolygons` 的双点裁剪路径会保留裁剪得到的两个候选点，第589–618行没有逐点按0.02米推测距离筛掉较大的正间隙。

该候选点是否产生法向冲量，还要结合间距和接近速度，由推测约束处理。正间隙候选点不等于已经接地，更不能无条件给它着地支持冲量。
例如暂不考虑转动，取较高点间距 \(s=0.68404\) m、\(h=1/60\) s、接近速度 \(v_n=-1\) m/s，则 \(v_n+s/h=-1+41.0424=40.0424\) m/s，满足推测不穿透条件；从零累计冲量开始时，这个点不需要新增法向冲量。

单角首先接触后，重力与接触冲量通常让盒子转向平放。正确验收应同时检查候选几何、`separation`、实际冲量和转动方向，而不是要求20度斜盒子永远保持20度，也不是仅凭高差强制流形只留一点。
本版 `b2CollidePolygons` 包含单点顶点情形与裁剪情形。
定位：[流形生成](../src/manifold.c)，702–1028行；例如832–847行为一个单点分支，1015–1019行为重叠裁剪路径，589–618行为双点构造。完整正分离候选算例见[第06章](./06-SAT裁剪与链段接触.md)。

## 10. M4：把一次冲量升级为顺序冲量

一个盒子可能同时接触两个物体，一个接触点更新速度会改变其他接触点看到的相对速度。
因此一次遍历通常不能同时满足所有约束。
顺序冲量采用迭代：每次处理一个约束，立刻修改刚体速度，让后面的约束看到最新结果。
它是迭代求解耦合系统，不是“每遍把完整碰撞冲量重复打一次”。

### 10.1 接触缓存最小状态

| 字段 | 含义 |
|---|---|
| `bodyA/bodyB` | 稳定配对关系 |
| `featureId` | 几何特征标识，用于匹配接触点 |
| `normal` | 从A到B的单位法线 |
| `anchorA/anchorB` | 相对质心的锚点 |
| `separation` | 有符号间距 |
| `normalMass` | \(1/K_n\) |
| `normalImpulse` | 当前累计法向冲量 |
| `tangentImpulse` | 当前累计切向冲量 |

接触点不能仅凭数组下标认定与上一帧相同。
物体移动或参考边切换后，点的顺序可能改变；错误复用缓存会给错误位置打冲量。
第一版可用稳定的边/顶点特征编号，匹配不确定时宁可清空缓存。

### 10.2 为什么钳累计量，而不是只钳本次增量

令当前累计冲量为 \(\lambda\)，根据残余法向速度算增量：

\[
\Delta\lambda=-M_n(v_n+b),\qquad M_n=1/K_n.
\]

b 是速度偏置，单位米每秒。
零偏置时约束试图消除接近速度；负偏置可产生有限的分离速度以修重叠。
单边接触只能推开，不能拉住，故累计冲量需要满足 \(\lambda\ge0\)：

\[
\lambda_{new}=\max(\lambda_{old}+\Delta\lambda,0),
\qquad
\Delta\lambda_{apply}=\lambda_{new}-\lambda_{old}.
\]

实际只应用差值 \(\Delta\lambda_{apply}\)。
这个差值可以为负，表示撤回之前过大的推力，但累计量仍非负。
如果把每次增量也钳为非负，迭代就无法撤回错误，容易把物体越推越快。
定位：[接触求解](../src/contact_solver.c)，`b2SolveContacts_Overflow`，308–328行。

### 10.3 简单偏置和推测约束的符号

对于重叠，教学偏置可取：

\[
b=\frac\beta h\min(s+\sigma,0).
\]

它非正。目标 \(v_n=-b\ge0\)，因此修正方向是分离而不是继续挤压。
对于仍有间隙 \(s>0\) 的推测接触，要求下一步不跨过表面：

\[
s+h v_n\ge0
\quad\Longrightarrow\quad
v_n+\frac sh\ge0.
\]

所以正间隙偏置为 \(b=s/h\)，它允许一定接近速度，不代表把远处物体立即推开。
本版使用软约束系数和接触速度钳制处理重叠，不能把上述简单硬偏置冒充完整源码。
对应：[接触求解](../src/contact_solver.c)，275–294行。

## 11. 摩擦：等法向冲量可靠后再限制切向

取切向 \(t=R(n)=(n_y,-n_x)\)，它与法线垂直且为单位向量。
切向相对速度 \(v_t=(u_B-u_A)\cdot t\)。
通过与法向相同的有效质量推导，可得候选切向增量。
库仑摩擦以累计法向冲量作为上限：

\[
|\lambda_t|\le\mu\lambda_n.
\]

\(\mu\) 无量纲，\(\lambda_t,\lambda_n\) 都是冲量，量纲一致。
使用累计 \(\lambda_n\)，而不是最后一次可能很小甚至为负的法向增量。
例如 \(\mu=0.5\)、\(\lambda_n=4\,N\cdot s\)，切向累计量必须在 \([-2,2]\,N\cdot s\) 内。
若候选累计切向量为-3，则钳到-2。
本版接触摩擦在 Relax 分支执行，见 [接触求解](../src/contact_solver.c)，331–385行。
教学硬约束版本可以每次法向遍历后求摩擦，但要明确它与本版分阶段实现不同。

## 12. 热启动：缓存有用，但不应变成重复施力

接触持续时，上一时段的约束冲量通常是下一时段的有用初值。
热启动先把缓存冲量应用到速度，再让当前迭代只修正残差。
当前累计值也必须设置为该缓存值；否则应用过缓存、累计却从零开始，会重复计算。
固定步长下可先直接复用，变步长时需要考虑缓存冲量的时间尺度，不能无条件照搬。
法线或特征变化过大时，应重置或重新匹配。

本版准备阶段将历史冲量按是否启用热启动复制进约束，见 [接触准备](../src/contact_solver.c)，112–114行。
热启动实际应用见 `b2WarmStartContacts_Overflow`，184–195行。
关闭热启动应该用于比较收敛速度和残差，不应把“关闭后必须倒塌”当成正确性的硬指标。
充分迭代、简单场景或其他设计下，不热启动也可能稳定。

## 13. M4成熟后的一步：阶段输入输出表

教学引擎到这一阶段，可以逐步调整为“先生成约束、求好速度、再积分位置”的结构。
对尚未重叠但即将碰撞的对象，需使用合适的候选扩展与推测接触；否则只能下一步才发现新碰撞。
初版也可保留最终有限位置投影，但必须明确它是独立的数值纠偏阶段。

| 阶段 | 读取 | 写入 | 必须维持的不变量 |
|---|---|---|---|
| 命令/质量更新 | 外部操作、形状 | 质量、逆量、待用力 | 不在遍历中无序删除对象 |
| 宽阶段 | 形状包围范围 | 候选物体对 | 无遗漏才谈减少误报 |
| 窄阶段 | 几何、相对变换 | 法线、点、间距、特征ID | 法线方向一致 |
| 准备约束 | 流形、逆量、缓存 | 锚点、有效质量、初始累计量 | 不修改几何造成隐式跳变 |
| 外力积分 | 力、重力、速度 | 新速度 | 不在子步中清掉大步外力 |
| 热启动 | 缓存冲量 | 速度 | 应用量与累计量一致 |
| 迭代求解 | 最新速度和约束 | 速度、累计冲量 | 法向累计量非负 |
| 位置积分 | 求解后的速度 | 质心、旋转 | 单位旋转保持有效 |
| 收尾 | 新状态 | 原点、缓存、事件 | 清力，合法时机发布事件 |

画一张每步日志表，记录每阶段之前和之后的状态，比只加更多迭代更容易发现 bug。

## 14. 用一个落地圆追踪整步状态

A为静态地面，B质量2千克，半径0.5米，圆心高度0.5米，初速度0。
重力 \(g_y=-10\)，步长 \(h=1/60\)，不启用恢复和摩擦。
法线从地面指向圆，为 \((0,1)\)。

| 阶段 | \(v_y\) | 法向累计冲量 | 圆心高度 |
|---|---:|---:|---:|
| 初始 | 0 | 0 | 0.5 |
| 重力积分 | -1/6 | 0 | 0.5 |
| 接触求解 | 0 | 1/3 N·s | 0.5 |
| 位置积分 | 0 | 1/3 N·s | 0.5 |

因为有效逆质量 \(K=1/2\)，冲量 \(j=(1/6)/(1/2)=1/3\,N\cdot s\)。
除以步长可还原平均支持力：\(j/h=(1/3)/(1/60)=20\,N=mg\)。
这说明静止支撑不是“没有接触冲量”，而是每个时间段的重力作用由向上冲量抵消。
后续帧若启用热启动，支持冲量可作为初始猜测，但不能无条件再额外加同一完整支持量。

## 15. 当前 Box2D 的阶段位置与教学版本的差别

外层 `b2World_Step` 位于 [世界实现](../src/physics_world.c)，894–1054行。
949–953行更新宽阶段候选；958–965行建立大步和子步时长；986–998行执行窄阶段和求解。
本版求解循环位于 [求解器](../src/solver.c)，`b2SolverTask`，1082–1158行。
真实每个子步为：积分速度 → 热启动 → 带偏置Solve → 积分位置 → Relax。
`ITERATIONS` 和 `RELAX_ITERATIONS` 在29–30行均为1，但子步循环会反复推进时间。
这不同于固定几何上重复8次冲量，也不同于教学 M2 的位置推进后一次碰撞后处理。
恢复与摩擦在当前接触 Relax 分支中处理，不另照抄历史阶段注释。
最后 `b2FinalizeBodiesTask` 用增量更新世界质心与旋转，重建刚体原点，并清空力和力矩。
定位：[求解器](../src/solver.c)，604–633行。

## 16. M5以后：按暴露的问题增加优化

| 观察到的问题 | 先检查正确性 | 确认后再优化 |
|---|---|---|
| 单圆落地反向弹飞 | 法线、相对速度和冲量符号 | 不要先加迭代掩盖 |
| 斜盒子行为奇怪 | 惯量、力臂、点速度、流形 | 更稳的接触生成 |
| 堆叠收敛慢 | 累计钳制、缓存匹配、摩擦上限 | 热启动、子步、软约束 |
| 配对数量过大 | 是否重复A-B/B-A | 网格或动态AABB树 |
| 静止场景仍很耗时 | 是否每步重建所有数据 | 接触复用、睡眠 |
| 远离原点后抖动 | 单位、绝对坐标相减 | 相对坐标、大世界位置 |
| 高速穿透 | 是否仅测两个离散端点 | 推测接触、CCD |
| 单核成为瓶颈 | 热点与内存访问测量 | 数据拆分、图着色、SIMD |

先做子步时，\(h=\Delta t/N\)，外力在整段 \(\Delta t\) 内保持，不能少施或多施。
先做宽阶段时，拿暴力配对当真值检查是否漏对，而不只比较运行时间。
先做睡眠时，不要让支撑链上相关物体错误地部分睡着；后续需要按连接岛管理唤醒和睡眠。
并行改变读写时序后，必须重新核验结果；“同样公式并行执行”不自动保证同样浮点顺序和位级结果。

## 17. 可量化验收，而不是凭画面感觉

### M1：积分

- 固定步数自由落体与第03章数据表匹配。
- 无力时匀速，质量变化不改变重力加速度。

### M2：圆碰撞

- 等质量完全弹性对撞交换速度。
- 非弹性对撞法向相对速度消失，但整体动量保持。
- 已分离对象不出现法向吸引冲量。
- 同心、零质量响应和零时间步有明确处理。

### M3：旋转和盒子

- 偏心冲量产生符合叉积符号的角速度。
- 接触点数由实际几何决定，允许单点和双点。
- 盒子静止平放时不因丢掉有效接触而持续无故旋转。

### M4：堆叠

固定物体尺寸、质量、摩擦、恢复系数、步长、迭代数、子步数与测试时长。
例如记录10个1米盒子在5秒后的最大穿透、顶部偏移、最大速度与累计冲量残差。
“几厘米”应相对场景单位制定为验收阈值，不是所有尺寸和质量比都通用的保证。
比较开关热启动、迭代次数和子步数的结果，确认变化能解释，而非只挑一张好看的截图。

## 18. 手算题与答案

### 题一：配对复杂度

100个物体的全配对数量是多少？
答案：\(100\times99/2=4950\)，不是10000，也不是9900。

### 题二：接触力与冲量

质量3千克物体在 \(g=10\,m/s^2\) 的地面静止，\(h=1/60\)，每步平均支持冲量多少？
答案：\(mgh=3\times10/60=0.5\,N\cdot s\)。
若分4个子步，每子步理想支持冲量为0.125，总量仍为0.5。

### 题三：累计冲量撤回

已有法向累计冲量5，本次求得增量-7，应应用多少？
答案：新累计 \(\max(5-7,0)=0\)，实际应用 \(0-5=-5\)。
不能应用-7使累计变负，也不能只允许非负增量而不撤回任何旧冲量。

### 题四：两个底角是否都碰到地面

半宽1米盒子倾斜20度，一底角刚接触，另一底角离地多少？
答案：\(2\sin20^\circ\approx0.68404\,m\)。
它说明高角尚未几何触地；不能据此断言当前 Box2D 流形会删除它，也不能给它无条件的着地支持冲量。是否产生冲量，还要结合正分离量和接近速度判断。
